# 🎮 İsim Şehir Hayvan — Neşeli Kelime Yarışı

Çocuklara uygun, neşeli, bol etkileşimli ve **veritabanı gerektirmeyen** İsim Şehir Hayvan web oyunu. **GitHub Pages** üzerinden ücretsiz yayınlanabilir ve farklı cihazlarda (telefon, tablet, bilgisayar) oda koduyla gerçek zamanlı oynanabilir!

## ✨ Özellikler
- **Veritabanısız Çok Oyunculu (WebRTC / PeerJS):** 4 haneli oda kodu veya davet linki (`?oda=K7M2`) ile farklı cihazlardan anında bağlantı.
- **Tek Oyunculu & Bot Arkadaşlar:** Robo-Bot, Bilge Tilki ve Hızlı Panda ile tek başına veya arkadaşlarınla birlikte oyna.
- **Bilge Baykuş İpucu Sistemi & Güçlendiriciler:** İpucu (`💡`) ve `+15 Saniye` (`⏰`) güçlendiricileri.
- **Canlı Emoji Tepkileri & Konfeti Podyumu:** Oyun sırasında arkadaşlarına tepki gönder, tur sonunda podyumda kutla!
- **Türkçe Duyarlı Doğrulama & Puanlama:** `İ/ı` uyumlu baş harf kontrolü (`+15` Tek Bilen, `+10` Benzersiz, `+5` Ortak, `0` Boş/Yanlış).

## 🚀 GitHub Pages ile Nasıl Yayınlanır?
1. Bu klasörü GitHub'da yeni bir depoya (repository) yükle (`index.html`, `styles.css`, `js/`).
2. GitHub deposunda **Settings → Pages** menüsüne gir.
3. **Source** kısmından `Deploy from a branch`, dal olarak `main` ve klasör olarak `/ (root)` seçip **Save** butonuna bas.
4. Birkaç dakika içinde oyunun `https://<kullanici-adin>.github.io/<depo-adin>/` adresinde yayında!
